# kindhuman-snapshots

Read the contract. Retrieve only the person's approved Moments through an available authorized adapter or explicit local export. Ask for the selection or use a selection already supplied. Preserve record IDs and revisions, known dates and the person's own words; leave unsupported views empty.

Present a dated Snapshot proposal. Do not infer age, life events or a narrative arc to fill gaps. The person must approve the exact selection and framing. With a real adapter, preserve a fixed version and read it back; later edits to Moments must not silently rewrite the Snapshot.

The current CLI has no Snapshot or upload command. It can support a local proposal only. State that limit and keep the proposal private until the server integration exists. Publishing a Snapshot requires separate review of everything it exposes.
